# Comic Free 日常阅读版

Status: implemented (local deterministic acceptance and Windows launcher verified)

## 已确认范围

用户确认在现有 MVP 基础上开发 Windows 一键启动、浏览器阅读、Suwayomi 在线来源优先的阅读器。沿用现有本机 Node 26、pnpm 10、Java 21；本轮不包含安装包、运行时下载、本地漫画导入或云同步。

- 双击启动：检查本机依赖，启动 Local Core 和 WebUI，确认就绪后打开浏览器。退出沿用已有安全关闭流程。
- 首次设置：保存 JAR 路径、明确批准的 SHA-256、内部端口和可选代理。保存不会立即执行第三方代码，重启生效；错误可恢复。
- 中文界面：书架、找漫画、阅读、设置四个入口，简洁内容优先布局。
- 阅读体验：单页、纵向连续阅读、键盘翻页、章节切换、适应宽度；输入框中的按键不应触发翻页。
- 续读：明确加入书架后自动保存进度；翻页、跨章、重新搜索同一作品均保留同一个书架条目；最近阅读优先显示；保存失败可见且可重试。

## 保留的不变约束

沿用 Comic Free 自有 Library Item、Source Binding 和 Reading Progress 身份，Host 数字 ID 和图片地址保持临时状态。来源失效或刷新不得删除本地数据；已有删除、乱序请求和并发失效防护继续成立。数据留在本地 `.local-data`。环境变量启动仍兼容。
